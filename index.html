"Automation may assess, measure, calculate fingerprints, and invalidate stale records; automation may NEVER invent or forge a human decision."

Dual-Layer Architecture

Built for Real-World AI Code Delivery

AI code generators write software at unprecedented scale. Traditional PR reviews miss subtle semantic modifications and stale approvals. HAIRS delivers mathematical and structural certainty.

⧉

Normalized File Hashing

Calculates sha256-nlf: over normalized content. Strips BOMs and unifies CRLF line breaks. Reverting code automatically restores review freshness without human re-review.

✧

Roslyn AST Fingerprints

Computes a deterministic 6-character hex hash over syntactic AST tokens. Safe against benign whitespace wraps, but immediately invalidates human seals upon logic or semantic modifications.

⚖

Popperian Falsification

High and Critical security units require an observable // Hairs-Falsified-If: criterion sentence defining under what concrete conditions the unit is falsified.

⚓

Syntax-Anchored Notes

Review questions, concerns, and todos bind to exact code fragments instead of fragile line numbers. Relocation states (Anchored, Moved, Ambiguous, Orphaned) persist across edits.

◆

Deterministic CI Gates

Enforces strict consistency rules (J1 through J11) via deterministic exit codes. Under --release, any pending, stale, or unannotated unit blocks CI with actionable GitHub annotations.

⚡

Zero Host Coupling

Completely decoupled from editor harnesses and UI platforms. Ships as a pure .NET 10 solution (Hairs.slnx), core library, and CLI with 375 tests passing in < 1 second.

Developer Quickstart

Get Started in Minutes

Install the CLI tool, configure your component, and integrate automated verification into your CI workflow.

STEP 1: CONFIGURATION

hairs.config.json

Place this configuration file at your project or component root to opt in:

{ "schema": 1, "component": "PaymentService", "projects": [ "src/Payment/Payment.csproj" ], "artefacts": { "report": "CODE-ASSURANCE.md", "humanReview": "HUMAN_REVIEW.md", "manifest": "hairs.manifest.json" } }
STEP 2: IN-SOURCE ANNOTATION

Declaration Syntax

Human and AI attestations live directly above C# declarations:

// Hairs-AI: Origin=AI; IP=Low; Security=High; Resources=2; Fingerprint=4A3BFD // Hairs-Falsified-If: an unauthorized user can charge an unverified card // Hairs-Human: EB; Fingerprint=4A3BFD public async Task<Result> ChargeAsync(Card card, decimal amount) { // ... audited implementation }
Command Line Interface

CLI Commands & CI/CD Workflow

Automate scanning, generation, and strict release gating in local terminals and continuous integration pipelines.

File Review & Freshness Checks

Evaluate repository review coverage and verify that edited files have fresh reviews:

# Generate repository coverage report (Markdown + JSON) hairs coverage --root . --markdown coverage.md --json coverage.json # Fail if changed files have stale reviews hairs check --root . --changed changed-files.txt --fail-on-stale

Declaration Assurance Gates

Audit, insert, generate structural fingerprints, and enforce release verification:

# Discover units & generate fingerprints hairs assurance list --root . --json units.json hairs assurance generate --root . # Strict release gate (Blocks if any unit is not VERIFIED) hairs assurance check --root . --release
Consistency Verification

Deterministic Rules (J1 – J11)

Automated rules verified by hairs assurance check to guarantee code integrity.

Rule Domain Verification Description CI Impact
J1 Coverage Identifies relevant C# declarations lacking required assurance blocks. Error
J2 Grammar Detects syntax violations, invalid keys, or malformed annotation lines. Error
J3 Fingerprints Enforces sealed fingerprints. Detects placeholder TBF or AST hash divergence. Error
J4 Human Decision Prevents automation from forging or synthesizing human reviewer aliases. Error (Critical)
J5 Headers & Reports Ensures generated file headers, banners, and markdown reports match disk state. Error
J6 Directives Flags forbidden preprocessor directives inside covered source components. Error
J7 Manifest Verifies inventory parity between hairs.manifest.json and source tree. Error
J9 Claims Rejects unsupported claims or unauthorized signoffs in criterion prose. Error
J10 Criteria Mandates // Hairs-Falsified-If: on High and Critical security declarations. Error
J11 Release Gate Blocks release if any covered unit is not in VERIFIED or EXEMPT state. Blocks CI Exit 1
